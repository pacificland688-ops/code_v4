## 3. 2018 / 2019 专项分析

### 2018（熊市）

| 指标 | V3 | V4 R2 |
|------|----|-------|
| 年化超额 | -3.3% | +1.3% |
| 最大回撤 | -32.8% | -30.8% |
| 换手率 | 29.2% | 12.0% |

**解释**: V4 R2 在 2018 年表现优于 V3，得益于防御性配置（低波动因子主导）在熊市中提供保护。低换手率也降低了交易成本。

### 2019（牛市/复苏）

| 指标 | V3 | V4 R2 |
|------|----|-------|
| 年化超额 | +1.0% | -17.2% |
| 最大回撤 | -13.8% | -12.5% |
| 换手率 | 34.8% | 13.1% |

**解释**: V4 R2 在 2019 年大幅落后 V3。2019 年市场强劲反弹（沪深 300 +34.9%），防御性策略在牛市中必然跑输。V4 R2 的纯防御配置（volatility_60_cs 权重 100%）无法捕捉牛市的 alpha 机会。

## 5. 归因分析

V4 R2 相对 V3 的变化可以归因于：

1. **因子构成差异**: V3 是多因子复合策略（价值+动量+反转），V4 R2 当前仅为单因子防御策略（volatility_60_cs）。
2. **换手率大幅降低** (30.8% → 14.4%)：表明 V4 R2 持有周期更长，交易成本更低。
3. **回撤改善** (-19.3% → -17.3%)：防御特性确实降低了最大回撤。
4. **牛市表现恶化**：2019、2020 年大幅跑输，因为缺乏 alpha 因子捕捉趋势性机会。

## 6. 结论

| 评估维度 | 结论 |
|---------|------|
| 相对 V3 胜出年份 | 4/8 → 未达到 5/8 建议标准 |
| 平均超额差异 | -3.8% → 未达到 >0 要求 |
| 2018 恶化 | 无恶化，R2 优于 V3 |
| 2019 恶化 | 大幅恶化 (-18.2%)，有明确解释（防御策略在牛市中必然跑输） |
| 整体判断 | V4 R2 当前不构成对 V3 的改进；本质是防御-only 策略，非完整 alpha 策略 |

**建议**: 在 gate 产生 PASS alpha 因子后重新构建候选池，再与 V3 对比。
