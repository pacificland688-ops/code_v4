## 边界

- 本报告只读取已完成的 Phase 2 diagnostics，不重跑策略、不改参数、不搜索配置。
- 正式验证集只使用 2017-2024；2025 不进入本报告；2026 只作为 YTD 观察。
- 持仓风格暴露使用信号日前最近一次因子值；技术因子最大滞后 14 天，基本面因子最大滞后 120 天。

## 核心结论

- D 相对 C 在验证集 7/8 年改善，平均年化超额差 1.70%。
- D 相对 A 在验证集 5/8 年改善，平均年化超额差 4.56%。
- D 自身平均年化超额为 -6.37%，正超额年份 2/8；仍不是生产候选。
- B dynamic 相对 A 只有 4/8 年改善，平均年化超额差 -1.89%，全候选动态 IC 路线未通过冻结验证。
- B 自身平均年化超额为 -12.83%，说明单纯打开全因子候选池没有解决问题。

## 判断

1. D 的方向比 C 更接近“不同市场用不同 sleeve”，但这次改善来自基础权重、平滑速度、换手约束和 overlay 的组合效应。
2. D 在多数年份改善 C，却仍然平均负超额，说明 regime 映射还没有把有效因子暴露稳定转成收益。
3. 当前结论应维持为研究候选，不应上线；下一步应做固定参数下的交易成本、持仓重合、行业/市值暴露和失败月份拆解，而不是继续调参。
