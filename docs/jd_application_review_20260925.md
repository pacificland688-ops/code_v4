## 4. 面试主案例怎么讲

研究假设：板块同步大跌后，部分个股可能因短期价格压力产生修复机会；需要识别修复确认、入场价格与失败退出，检验收益是否能覆盖风险和成本。这是待证伪假设，不是已证明的市场规律。

讲述顺序：

1. 定义候选事件与当时可得数据，保留未入场分母。
2. 解释确认后下单、次日代理撮合、订单到期和退出重试，避免事后筛选已成交交易。
3. 从独立事件账本转向共享资金，处理预算预留、同名冲突、资金竞争和连续估值。
4. 给出真实历史结果，拆分仓位利用率、毛利润和费用。
5. 展示亏损诊断，说明为什么不直接上更复杂模型或提高仓位。
6. 说明停止推进的依据，以及哪些新证据才值得启动下一轮研究。

三分钟开场草稿：

> 我做了一个 A 股量化研究平台，包含截面多因子和板块事件两条研究线。最深入的案例是板块恐慌后的修复策略：先定义当时可见的确认信号，再把入场限制、退出义务和资金竞争放进回放。214 个候选事件对应 2140 个候选键，共享资金历史回放完成 281 笔交易。在冻结研究费率和日收盘代理成交假设下，年化净收益约 0.057%，最大回撤约 10.89%。我进一步区分了价格本身亏损、费用转亏和浮盈回吐，发现多数亏损交易扣费前已亏损。由此没有继续用复杂模型追逐历史收益，而是记录经济证据不足并停止推进当前独立账户版本。这个案例能展示我如何形成假设、实现回测、核对结果并作研究取舍；真实交易执行和新的独立样本验证仍未完成。

不要以“失败也很优秀”结束。面试官更关心：你通过哪些具体分析缩小了问题范围，下一步如何提高研究效率。

## 6. 高频追问与回答要点

**策略没有证明赚钱，项目价值在哪里？**

承认盈利证据不足；随后展示可复核的研究流程、问题定位和资源取舍。不要把工程正确性当成 Alpha 的替代品。若用人方要求成熟策略交付，这确实是缺口。

**为什么单边费用设为 0.5%？**

它是冻结研究假设，不是经过真实账户校准的历史费率。可以展示固定成交的费用归因，但若换费率，需要重新定义账户和执行假设并回放；不能直接声称降费即可实盘。

**低仓位导致收益低，放大仓位不就可以了？**

平均仓位约 5.88%，最高已约 49.45%，且经历约 10.89% 回撤。平均仓位不是可用于机械倍增收益的分母；放大还会改变资金竞争、流动性和风险。

**为什么不训练更复杂模型？**

现有描述性差异尚未证明预测能力，同一历史被反复使用。先定义可用输入、对照基线和新的验证协议，再决定模型复杂度。

**VWAP、AVWAP、IS 做到哪一步？**

backtest/execution.py 提供日级 amount/vol 的 VWAP 估计及 exec/vwap-1 比较；函数名 implementation_shortfall 不能证明完整 IS 算法。事件中的 AVWAP 是信号锚点。当前材料没有提供分时拆单、盘口冲击模型与执行算法实盘证据。

**实盘监控做到哪一步？**

展示 RiskGate、paper broker 和日终监控代码，并明确它们与真单回执、券商柜台、资金核对和长期运行记录的边界。

**为分公司或财富客户创造什么价值？**

用一页材料讲清策略试图捕获的机会、资金占用、风险来源、适用限制与当前不可配置的原因。把这作为表达能力样稿，不虚构服务过的客户或培训场次。
