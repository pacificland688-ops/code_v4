## 2. 背景：什么是 primary_5d

### 2.1 基本定义

`primary_5d` 是竞争对手提出的光刻胶（photoresist）板块恐慌性下跌事件因子。

**核心公式**：

```text
primary_5d = (
    basket_ret_5d < 0
    AND (
        basket_ret_5d <= -0.05
        OR basket_ret_5d <= rolling_250d_quantile_10pct
    )
    AND down_stock_ratio_5d >= 0.50
)
```

**冻结参数**：

```yaml
primary_5d:
  return_window_days: 5
  absolute_threshold_pct: -5.0
  quantile_window_days: 250
  quantile_threshold_pct: 10.0
  breadth_window_days: 5
  breadth_threshold_pct: 50.0

event_clustering:
  max_gap_trading_days: 5
```

### 2.2 核心约束

| 参数 | 值 |
|------|-----|
| 核心股票池 | 4 只（晶瑞电材、南大光电、彤程新材、上海新阳） |
| 完整研究池 | 15 只（含 core / adjacent / mapping） |
| 基准指数 | 000300.SH（沪深 300）用于市场状态；931865.CSI（中证半导体产业）用于超额 |
| primary_5d 事件簇 | 71 个（回顾性聚类后） |
| 20 日收益有效事件 | 64 个 |
| 非重叠有效事件 | 42 个 |
| bull/neutral 非重叠事件 | 约 26 个 |
| 年均交易频率 | bull/neutral 下约 3 次/年 |
| 账户约束 | 只能买一只股票 |
| 执行方式 | t+1 close 入场，固定持有 5/10/20 日 |

## 3. 三轮辩论脉络

### 3.1 Round 1 — 我们的初始评审

**核心指控**（13 个问题，按严重程度分级）：

| 级别 | 数量 | 代表性问题 |
|------|:----:|-----------|
| 🔴 阻断级 | 3 | 最后触发日聚类存在隐性未来函数；basket→Top1 范畴错误；样本量不足以支撑统计推断 |
| 🟠 重大 | 4 | 市场状态定义的循环依赖；t+1 close 与恐慌修复时间线错配；Top1 排序规则隐含偏倚；成本假设低估 3-5 倍 |
| 🟡 中等 | 4 | 聚类 5 天间隔缺乏经济依据；OOS 期间不对称；版本管理可能引入幸存者偏差；LOO 在小样本中无效 |
| 🔵 次要 | 2 | 「因子」定义过于宽泛；SHA256 过度工程化 |

**核心结论**：

> 用 basket 层面的统计证据来论证事件有效性，但要求用单票来承载交易，而这两者之间的统计鸿沟在光刻胶这种超窄板块中几乎不可弥合。

### 3.2 Round 2 — 对方回应

**事实纠错**（5 个，我们需承认）：

| 我们的错误 | 实际情况 |
|-----------|---------|
| 核心池约 10-20 只 | **4 只** |
| 成本主口径约 20 bps | **40 bps 往返**（2 × 20 bps） |
| 2024-2026 作为整体 OOS | 数据截止 **2025-12-31**，2026 仅计划范围 |
| 市场状态公式未给出 | **公式已明确**：close vs MA120 + 60d return |
| LOO 在 4 只中无意义 | 在 4 只中是**成分支配诊断**，非传统稳健性检验 |

**对方接受的关键批评**：

- 最后触发日不能作为实时交易时点 → 提出 `research_episode_date` vs `live_signal_date` 双口径
- 增加「可交易 basket」层（四层框架）
- 接受样本量批评，提出分层阈值
- 接受成本需上调
- 接受版本治理需累计计数

**对方回避的问题**：

- 4 只核心股 + 移除 1 只即反转 → 降级为「dominance diagnostic」
- 四层框架 Layer 1 的不可证伪性 → 未充分回应
- Phase 0 通过条件过低 → 「不转为明显负值」不是策略可用标准
- 缺少 Top1 长期失败的退出条件
- 首次触发 vs 最后触发的收益差未被正视

### 3.3 Round 3 — 对方最终裁决文档

**文档**：`docs/photoresist_primary_5d_competitor_response_review.md`

**核心让步**：

```

"Statistical Event Effect"                → "Fixed-Universe Basket Pattern Under Audit"
"sector_common_reversal_effect"           → UNPROVEN
```

## 4. 对裁决文档的逐条分析

### 4.1 最后触发日偏差（§3）

**共识部分** ✅：

- 区分 `panic_gate`（实时可计算）、`retrospective_episode_date`（回顾性）、`live_signal_date`（在线状态机）
- Phase 0 必须输出 first-trigger vs last-trigger 的逐事件配对检验

**争议部分** ⚠️：

文档声称「偏差方向不一定总是向上」，给出 5 条理由。分析如下：

| # | 对方的理由 | 评估 |
|:--:|-----------|------|
| 1 | 最后触发日不一定是事件最低点 | 部分成立。但 rolling 5d return 条件下，最后触发日大概率晚于首次触发日，入场更晚 |
| 2 | primary_5d 是滚动 5 日收益条件，不是当日创新低条件 | 成立但无关。问题不在是否创新低，而在使用事后信息选择时点 |
| 3 | 市场可能反弹后仍因滚动窗口较差而再次触发 | **这条反而支持偏差向上的论点**——如果反弹后再次触发，最后触发日恰好在反弹起点附近 |
| 4 | 最后触发日后仍可能继续下跌 | 成立但不否定平均偏差方向 |
| 5 | 延后入场同时延后退出，收益差不只由入场价格决定 | 成立，但入场偏差是主要驱动因素 |

**结论**：对方在修辞上将「确定性向上偏差」弱化为「不一定向上」，这是降级处理。在均值回归策略中，事后选择时点的偏差方向是系统性的，偏差幅度需通过配对检验确认，这一点倒没有分歧。

### 4.2 四只核心股与 LOO 反转（§4）

**对方接受** ✅：

- 当前结果未通过跨核心成分共同性检验
- Layer 1 应降级为 `Fixed-Universe Basket Pattern Under Audit`
- 删除彤程新材后 20 日篮子结果转负

**对方坚持** ⚠️：

- 「LOO 反转不能单独证明信号不存在」（§4.1）

**分析**：

对方的 4 条辩护：

| # | 辩护 | 反方分析 |
|:--:|------|---------|
| 1 | 彤程新材自 2020 年才进入 PIT 核心池，并非全历史固定 25% 权重 | 成立但无关——问题不在于权重是否恒定，而在于任何时点的篮子结果高度依赖单一成分 |
| 2 | 删除彤程新材不仅删除收益贡献，也改变篮子构成和有效事件 | 正是因为改变太大才说明集中度问题，不是反驳 |
| 3 | 删除 1 只 = 结构性重定义 4 只股票的篮子，不是微小扰动 | 同意——但正因如此，4 只股票对得出「板块效应」结论的样本量不够 |
| 4 | LOO 不能区分彤程是主题主要载体还是偶然历史赢家 | 同意——但这恰恰是需要区分的关键问题，当前数据无法区分 |

**真正的问题**：如果彤程新材与其他 3 只在事件期的收益相关性接近于零或为负，那么篮子平均收益不是在测量板块修复，而是在测量恰好包含彤程新材的组合结果。对方新增的共同性诊断（§4.2）正是为了回答这个问题——但诊断尚未执行。

**LOO 阈值 -50 bps 的语义矛盾**（§6.2 第 9 条）：

```text
操作化：每个 LOO 组合的 20 日平均超额 >= -50 bps
```

这意味着：

| 场景 | 完整篮子超额 | LOO 组合超额 | 是否通过 | 问题 |
|------|:----------:|:----------:|:------:|------|
| A | +200 bps | -49 bps | ✅ 通过 | 超额从 +200 跌到 -49，方向已反转，249 bps 的变化由单一股票驱动 |
| B | +40 bps | -51 bps | ❌ 失败 | 超额从 +40 跌到 -51，变化 91 bps，反而比场景 A 更不极端 |

**建议修正**：LOO 条件应同时要求：

```text
LOO 组合超额 > 0（方向不反转）
AND LOO 组合超额变化幅度 < 总超额的 50%（非单一股票驱动）
```

### 4.3 四层框架与逃逸舱风险（§5）

**改善** ✅：

- Layer 1 增加了 7 项可证伪条件
- 允许 `sector_common_effect = FAILED` 而保留 `fixed_basket_pattern = OBSERVED`
- 下游失败时 `single_stock_strategy_status = TERMINATED`

**剩余风险** ⚠️：

虽然文档区分了 `scientific_status` 和 `strategy_status`，但没有明确以下转换条件：

```text
Layer 1 (Statistical) 通过 + Layer 2 (Tradable) 失败 + Layer 3 (Top1) 失败
→ 持续 N 年后应触发什么裁决？
```

当前框架允许这种状态无限持续——只要 Layer 1 的统计现象存在，就可以在每个新年度重新尝试 Layer 2 和 Layer 3。这是「研究许可证」风险的残余。

### 4.4 Phase 0 硬性门槛（§6）

**进步** ✅：

从「不转为明显负值」升级为 10 条量化条件。

**10 条条件逐条评估**：

| # | 条件 | 评估 |
|:--:|------|------|
| 1 | first-trigger 20 日成本后平均收益 > 0 | ✅ 合理的最低门槛 |
| 2 | first-trigger 20 日相对半导体平均超额 > 0 | ✅ 合理 |
| 3 | 非重叠事件收益中位数 > 0 | ✅ 中位数比均值更稳健 |
| 4 | 非重叠事件超额收益中位数 > 0 | ✅ 同上 |
| 5 | 超额胜率 > 55% | ⚠️ 55% 在 26 个事件中需要 15 次正超额，合理但统计 power 极低 |
| 6 | 严格 placebo p-value ≤ 0.10 | ⚠️ 4 只股票 + 26 个事件中 placebo 排列空间不足（见 §4.4.1） |
| 7 | 个股超额收益中位数 > 0 | ✅ 对 4 只股票，每只都必须 > 0，这是强约束 |
| 8 | 超过 50% 核心股票在多数事件中呈正超额 | ✅ 即 4 只中至少 3 只在 >50% 的事件中为正 |
| 9 | 剔除任一股票后不得从正向转为明显负向 | 🔴 -50 bps 阈值存在语义矛盾（见 §4.2） |
| 10 | 2024 和 2025 必须分别报告 | ✅ 合理 |

**经济幅度门槛**：

```text
20 日平均成本后收益 >= 2%
20 日平均相对半导体超额 >= 1%
```

**问题**：没有配套的统计 power 分析。

在 26 个样本中，假设单次收益标准差 15%：

- 均值标准误 = 15% / √26 ≈ 2.94%
- 检测 2% 均值的 t-stat ≈ 0.68
- 单侧 p ≈ 0.25

**这意味着即使你观察到 2% 的均值，在常规统计水平上也无法拒绝「真实均值为 0」的原假设。** 经济幅度门槛没有替代统计显著性检验——两者回答不同的问题。

#### 4.4.1 Placebo 检验的排列空间约束

在 4 只股票 × 26 个事件中：

- 股票层面的随机化只有 4! = 24 种排列
- 最小可达到 p-value = 1/24 ≈ 0.042
- 这虽然低于 0.10 的要求，但不是因为效应强，而是因为排列空间天然受限

这是一个被忽视的技术细节：**小样本 + 小股票池使得 placebo 的 resolution 本身就有限。**

### 4.5 年度门槛（§6.3）

**对方的规则**：

```text
2024 和 2025 不得同时为负
任一年度成本后平均收益不得低于 -3%
任一年度相对半导体超额不得低于 -2%
两年合并非重叠收益和超额必须为正
单一年份收益贡献不得超过总收益的 70%
```

**可以通过的组合示例**：

| 年份 | 平均收益 | 相对半导体超额 | 事件数（估计） |
|------|:------:|:------:|:------:|
| 2024 | -2.9% | -1.9% | 2-4 |
| 2025 | +5.1% | +3.9% | 2-4 |
| **合计** | **+2.2%** | **+2.0%** | **5-8** |

**问题**：

- 一年亏损 -2.9%、超额 -1.9% 仍然通过
- 在年均 2-3 次的频率下，单次亏损 -8% 就能把该年拉到 -3%
- 一次交易的偶然性 = 该策略一整年的表现
- -3% 的门槛无法过滤这种偶然性

**建议修正**：两个年度必须各自独立为正（不要求显著，但要求方向一致），或合并 bootstrap 90% CI 下限 > 0。

### 4.6 First-Trigger 失败处理（§7）

**值得肯定** ✅：

- 终止条件明确：平均收益 ≤ 0 OR 相对半导体超额 ≤ 0 OR placebo p > 0.10
- 禁止通过等待确认、第二次触发或新增技术指标继续修改同一版本
- 新经济假设必须登记为新候选

**剩余模糊** ⚠️：

文档只限制了 **Top1** 的版本数（最多 2 个），**未限制 primary_5d gate 公式自身的变体数量**。如果把 `absolute_threshold_pct` 从 -5.0 改为 -6.0 并称为 `primary_5d_v2_candidate`，是否受版本预算约束？文档在此处存在模糊地带。

### 4.7 在线冷却状态机（§8）

**设计** ✅：

```text
IDLE → 首次触发 primary_5d → 生成 live_signal → 转入 ACTIVE
ACTIVE → 固定持有期内不加仓/不换股/不因更强触发重新入场
ACTIVE → 退出后转入 COOLDOWN
COOLDOWN → 连续 5 个交易日 primary_5d=False 后返回 IDLE
COOLDOWN → 再次触发重置冷却计数，不产生新交易
```

**已解决的问题** ✅：

- 更强触发只记录为 `episode_intensity`，不触发换仓 → 避免了通过换仓重新引入事后选择
- cooldown=5 冻结，3 和 10 只做灵敏度分析

**未解决的问题** ⚠️：

如果 Phase 0 在 cooldown=5 下失败而在 cooldown=3 下通过，应如何裁决？文档禁止了「按收益挑选」，但没有规定不同 cooldown 导致结论翻转时的裁决规则。

### 4.8 Top1 版本预算和退出规则（§10）

**正面** ✅：

```text
最多允许 2 个正式 Top1 候选版本
每个版本最多 3 套预登记规则
不允许在同一历史区间无限重写
所有失败版本永久保留
```

**5 条强制终止条件** ✅：

1. 两个正式 Top1 版本均失败
2. 所有规则在 100 bps 往返成本后非正
3. 所有正收益规则均由单一股票贡献超过 50%
4. 冻结后的前向样本达到预设数量后仍无正超额
5. Phase 0 后续滚动监控失效

**终止后的处理** ✅：

- 不开发 Top1 v3/v4
- 不重新挑 primary_5d 阈值
- 不更换市场状态直到下一个独立研究周期
- 保留为描述性主题监控
- 建议调整「只能买一只」的账户约束或放弃该方向

这是整个文档中治理最严密的部分。

### 4.9 低频信号的用途边界（§11）

**对方承认** ✅：

> 当前 bull/neutral 非重叠事件合计约 26 个，年均约 3 次
> 不适合高频因子、高自由度机器学习、依赖大量交易快速收敛或要求逐年统计显著

**定位为**：

- 低频事件驱动信号
- 主题仓位辅助择时
- 人工复核候选
- 与其他独立信号组合后的触发条件
- 低容量、低风险预算策略

这个定位是诚实的。

## 5. 仍未解决的三个根本性矛盾

### 5.1 样本约束 vs 验证要求

```
bull/neutral 非重叠事件：约 26 个
年均交易次数：约 3 次
核心股票池：4 只
OOS 年份：2 年（2024-2025）
```

| 门槛类型 | 如果设太高 | 如果设太低 |
|----------|-----------|-----------|
| 统计显著性 | 永远无法通过（样本不足） | 无意义的形式主义 |
| 经济幅度 | 可能误杀真实但微弱的效应 | 噪声可能被误认为信号 |
| 年度稳定性 | 2 年过于依赖单次交易 | 任何方向都能找到解释 |

**这不是框架设计能绕过的——这是参数空间的硬约束。**

### 5.2 单票约束 vs 信号性质

恐慌修复的本质是 **cross-sectional 的均值回归**：

- 买 10 只超跌股票：约 7 只反弹，3 只继续跌 → 组合为正
- 买 1 只超跌股票：选中 7 只还是 3 只 → 很大程度上是运气

**在 4 只核心股中做 Top1，是把 cross-sectional 的信号降维成纯 idiosyncratic 的赌博。**

### 5.3 研究强度 vs 经济价值

```
研究投入：三轮辩论、四层框架、10 条硬性条件、状态机、版本预算、退出规则……
潜在收益：年均 3 次交易 × 预期单次超额约 1-3% ≈ 年化超额约 3-9%
```

研究投入与经济价值的比例是否合理，是一个在策略开发资源分配层面需要回答的问题。

## 6. 对我们的启示

### 6.1 正面启示（应借鉴）

| 对方做对了的 | 我们应该借鉴的 |

### 6.2 反面教训（应避免）

| 对方的问题 | 我们应该避免的 |
|-----------|-------------|
| 在 4 只股票的超窄池中做单票选股 | 确保因子在足够宽的 universe（≥ 100 只）中验证 |
| 用框架层级保护不可证伪的底层 | 每一层都应有独立的证伪标准和退出条件 |

| 多次查看 OOS 后再声称是干净的 | 使用嵌套 walk-forward，确保真正的 OOS purity |
| 在参数空间极小的领域做过度复杂的框架 | 框架复杂度应与样本量匹配 |
| LOO 阈值使用绝对值而非相对值 | 集中度/共同性检验应使用相对变化 |

### 6.3 针对我们当前 NO_ALPHA_SOURCE 状态的建议

1. **不要在窄板块中重复对方的错误。** Panic reversal 因子应在 broad market（全 A 或中证 800+）中验证。

2. **先解决数据基础设施问题。** 49 个因子 FAIL 的根源多数是数据覆盖（growth 0%）或 metadata 缺失（value LEAKAGE_METADATA_MISSING）。在数据问题解决前，panic reversal 因子即使 gate 通过也无法接入策略。

3. **将 shock_reversal sleeve 的 `abnormal_drop_reversal_5_cs` 纳入新一轮 gate 评估。** 这是我们对标 primary_5d 的因子，但尚未在 v4_r2 gate 体系中正式评估。

4. **建立我们自己的「可交易性验证」阶段。** 在因子通过 gate 后、进入 sleeve 组合前，验证因子在实际可交易股票池中是否仍然有效。参考对方的四层结构，但确保每一层都有独立的证伪标准。

5. **对比我们的 27 个 panic reversal 候选因子与对方的 primary_5d。** 记录哪些设计选择是更好的（我们的 broad market vs 对方的 4 只股票），以及我们应该从对方学到什么（公式冻结、事件聚类处理、cooldown 状态机）。

## 8. 最终裁决总结

### 8.1 对方在治理层面的进步（应该承认）

三轮辩论中，对方从「条件性事件因子已具备研究证据」退到「固定篮子统计现象尚待验证」。裁决文档在以下方面有实质进步：

- Layer 1 从 Statistical Event Effect 降级为 Fixed-Universe Basket Pattern Under Audit
- Phase 0 从定性模糊描述升级为 10 条量化硬性条件
- 设置了 Top1 的版本预算和 5 条强制终止条件
- 接受了 first-trigger 不可变通的终止规则
- 增加了在线冷却状态机的预冻结

### 8.2 对方仍然存在的问题（不应放过）

1. **LOO 阈值 -50 bps** 与「方向不反转」的语义矛盾
2. **年度门槛**在年均 2-3 次交易时无法过滤偶然性
3. **经济幅度门槛**没有配套统计 power 分析
4. **primary_5d gate 变体**缺少版本预算
5. **cooldown 参数**在不同值导致结论翻转时的裁决规则缺失

### 8.3 核心判断

> 这份裁决文档在治理层面比此前任何方案都更接近一个可被证伪的科学研究程序。但它最终没有解决参数空间硬约束带来的根本矛盾：26 个事件 + 4 只股票 + 年均 3 次交易，无论框架多严密，都无法为单票实盘策略提供足够可靠的证据基础。Phase 0 设置了正确的验证项目，但部分项目的执行标准（LOO 阈值、年度门槛）在关键细节上仍然过软，可能在统计噪声中给出虚假的「通过」信号。
