# D_regime_overlay 失败年份归因分析

生成日期：2026-06-11  
数据来源：`frozen_backtest_attribution.py` (2017-2024 冻结验证)  
策略：`D_regime_overlay` (less_reversal_faster_overlay)

## 1. 执行摘要

D_regime_overlay 在 2017-2024 的 8 年验证中，平均年化超额 -6.37%，正超额年份仅 2/8（2022、2024）。相对 C_regime_baseline 在 7/8 年有改善（平均 +1.70%），但改善幅度不足以扭转负超额。

| 年份 | CSI300 收益 | D 绝对收益 | D 超额 | C 超额 | D-C 超额差 | 主要失败层 |
|------|-------------|------------|--------|--------|-----------|-----------|
| 2017 | +21.9% | -0.7% | **-19.5%** | -19.9% | +0.39% | Alpha + Router |
| 2018 | -23.7% | -37.9% | **-17.5%** | -18.3% | +0.88% | Alpha (系统性) |
| 2019 | +36.2% | +18.3% | **-13.4%** | -13.7% | +0.37% | Alpha + 组合构建 |
| 2020 | +21.8% | +19.5% | **-4.2%** | -8.6% | +4.42% | Alpha (边际) |
| 2021 | -9.0% | -16.0% | **-7.0%** | -6.5% | -0.52% | Router + Alpha |
| 2022 | -21.2% | -12.8% | **+10.0%** | +8.7% | +1.32% | ✅ 正超额 |
| 2023 | -11.3% | -16.8% | **-1.9%** | -6.6% | +4.65% | 接近打平 |
| 2024 | +17.9% | +25.1% | **+2.5%** | +0.4% | +2.11% | ✅ 正超额 |

**核心发现：**

1. **Alpha 层是主要瓶颈**。底层因子池中仅 value 类 (ep_cs, bp_cs, sp_cs) 稳定通过 IC 门槛，技术/动量/反转因子多数未通过。Regime overlay 只能分配已有 alpha，不能创造 alpha。

2. **Regime router 在关键年份映射错误**：
   - 2017/2019 强牛市场中，range_bound 主导（60%+），高配 reversal 未能参与趋势收益。
   - 2021 风格切换年，reversal 配置反而轻微恶化。

3. **组合构建层有二次损失**。fast Top50 与 Phase2 实际持仓存在差距，交易约束（涨跌停、停牌、持仓延续）可能使得最优信号无法完全执行。

4. **防御 sleeve 在熊市保护不足**。2018 年即使防御权重最高，绝对亏损仍达 -37.9%，因为系统性下跌中几乎所有股票都跌。

## 2. 年度归因

### 2.1 2017：强牛市中的价值/反转错配

**市场背景：** CSI300 +21.9%，大市值、低估值蓝筹持续上涨。

**D 表现：** 绝对 -0.7%，超额 -19.5%。

**Regime 状态：**
- range_bound_prob: 59.7%（主导全年）
- trend_up_prob: 16.8%
- 主导 sleeve: volume_price (27.2%), reversal (22.9%)

**风格暴露（D 持仓 vs 市场）：**
| 因子 | D 平均暴露 | 方向判断 |
|------|-----------|---------|
| ep_cs | +0.32 | 价值暴露正常 |
| bp_cs | +0.17 | 价值暴露偏低 |
| reversal_5_cs | +0.41 | 反转暴露 — 在趋势市中失利 |
| momentum_120_cs | +0.19 | 动量暴露不足 |
| volatility_20_cs | +0.47 | 低波暴露 — 在强市中拖累 |
| log_market_cap_cs | -0.03 | 轻微大市值偏好 |

**失败根因：**
1. **Router 层：** range_bound 概率过高（60%），高配 reversal/volume_price，低配 momentum/trend。
2. **Alpha 层：** reversal 因子在 2017 年趋势市中全年失效，但 C baseline 高配 reversal（31.6%），D 虽降低至 22.9%，仍偏高。
3. **组合层：** 全年 50 个调仓周期中，D 仅在 30 个周期跑赢 C，改善幅度分散且微弱（平均周超额差 +0.008%）。

**D vs C 改善机制：** D 降低了 reversal 权重（31.6% → 22.9%），增加了 volume_price（22.6% → 27.2%）和 momentum（12.3% → 15.8%），这是正确的方向，但力度不够。

### 2.2 2018：系统性熊市中因子 alpha 失效

**市场背景：** CSI300 -23.7%，全面熊市，贸易摩擦+去杠杆。

**D 表现：** 绝对 -37.9%，超额 -17.5%。

**Regime 状态：**
- trend_down_prob: 49.0%（主导）
- range_bound_prob: 19.4%
- 主导 sleeve: defensive (29.2%)

**风格暴露：**
| 因子 | D 平均暴露 |
|------|-----------|
| ep_cs | +0.32 |
| reversal_5_cs | +0.44 |
| volatility_20_cs | +0.40 |
| defensive 权重 | 29.2% |

**失败根因：**
1. **系统性风险碾压 alpha：** 熊市中几乎所有因子 alpha 都被市场 beta 淹没。D 相对基准多跌 17.5%，说明防御配置未能有效对冲。
2. **Defensive sleeve 权重不足且定义过窄：** 即使 defensive 权重 29.2%，组合仍持有大量非防御股票。低波动不等于抗跌。
3. **D vs C 改善极其有限（+0.88%）：** overlay 在熊市中几乎没有调节空间。

**关键教训：** 纯多头的因子策略在系统性熊市中几乎不可能产生正超额，除非有行业/市值对冲或空头能力。这不应被视为策略失败而是策略边界。

### 2.3 2019：强反弹中价值因子严重跑输

**市场背景：** CSI300 +36.2%，年初估值修复+科技创新驱动。

**D 表现：** 绝对 +18.3%（正收益），超额 -13.4%（大幅跑输）。

**Regime 状态：**
- range_bound_prob: 35.6%（主导）
- high_volatility_prob: 22.5%
- trend_up_prob: 19.1%
- 主导 sleeve: reversal (26.0%)

**失败根因：**
1. **Router 识别错误：** 2019 年一季度的强劲反弹中，regime router 仍判定为 range_bound（35.6%）和高波动，未能及时切换至 trend_up。
2. **Reversal 主导在反弹中最受伤：** 反弹中前期超跌的股票反弹最猛（恰是 reversal 会卖出/回避的股票）。
3. **缺少 beta/momentum 暴露：** momentum_120 权重仅 13.8%，无法捕捉趋势。
4. **价值因子自身在 2019 年也不佳：** 2019 年反弹由成长/科技驱动，价值因子上半年表现弱。

**D vs C 改善**仅 +0.37%，说明 overlay 在此年份几乎无作为。

### 2.4 2020：最佳改善年份，但仍不够

**市场背景：** CSI300 +21.8%，疫情冲击后 V 型复苏，结构分化严重。

**D 表现：** 绝对 +19.5%，超额 -4.2%（D 最佳年份）。

**Regime 状态：**
- high_volatility_prob: 27.1%（主导）
- range_bound_prob: 25.8%
- trend_up_prob: 22.8%
- 主导 sleeve: value (24.5%)

**成功机制：**
1. **Value rotation 被正确激活：** value_multiplier = 1.20，value_weight 从 19.0% → 24.5%。
2. **High volatility 识别正确：** 2020 年 3 月暴跌和后续反弹中波动率极高。
3. **D vs C 改善 +4.42%** — overlay 最大的单年贡献。

**仍未转正的原因：**
1. **alpha 池的 value 因子贡献有限：** 即使 value 被正确高配，value 因子本身的超额在 2020 年并不惊人。
2. **Reversal 被降低但仍占 21.1%：** 在 V 型反转中反转因子表现不佳。

### 2.5 2021：风格切换年，Router 彻底失效

**市场背景：** CSI300 -9.0%，春节后风格剧烈切换，大消费→新能源/周期。

**D 表现：** 绝对 -16.0%，超额 -7.0%。**D 比 C 更差（-0.52%）。**

**Regime 状态：**
- range_bound_prob: 37.7%
- trend_down_prob: 22.2%
- high_volatility_prob: 23.1%
- 主导 sleeve: reversal (25.8%)

**失败根因（D 唯一跑输 C 的年份）：**
1. **Range-bound 主导但 reversal 全年失效：** regime router 在风格切换时误判为震荡市，高配 reversal。
2. **Overlay multipliers 全部接近 1.0**（无强信号）：reversal=0.97, momentum=1.01, defensive=0.84, value=0.86, volume_price=0.93。Overlay 几乎没有做出任何主动偏离。
3. **Defensive multiplier=0.84（低配防御）：** 在下跌市中降低防御配置，恰好错误。
4. **Value multiplier=0.86（低配价值）：** 错过了周期/价值风格。

**这是 regime overlay 路线最大的危险信号**：当 router 无法产生强信号时，overlay 可能随机漫步甚至反向。

### 2.6 2023：改善最大但样本已污染

**市场背景：** CSI300 -11.3%，全年震荡下行。

**D 表现：** 绝对 -16.8%，超额 -1.9%。

**D vs C 改善 +4.65%**（最大改善年份）。

**⚠️ 注意：** 2023 参与了候选形成（参数网格搜索），不是纯 OOS。改善可能包含过拟合。

## 4. 分层归因：Alpha vs Router vs 组合构建 vs 成本

### 4.1 Alpha 层（因子质量）

| 因子 | 2017-2024 mean IC | ICIR | 正向率 | 判断 |
|------|------------------:|-----:|-------:|------|
| ep_cs | ~0.03 | ~0.35 | ~55% | ✅ 通过 |
| bp_cs | ~0.025 | ~0.30 | ~54% | ✅ 通过 |
| sp_cs | ~0.022 | ~0.28 | ~53% | ⚠️ 边际 |
| reversal_5_cs | ~0.015 | ~0.18 | ~50% | ❌ 未通过 |
| reversal_20_cs | ~0.012 | ~0.15 | ~49% | ❌ 未通过 |
| momentum_120_cs | ~0.018 | ~0.22 | ~51% | ❌ 未通过 |
| rsi_14_cs | ~0.010 | ~0.12 | ~50% | ❌ 未通过 |
| volatility_20_cs | ~0.008 | ~0.10 | ~49% | ❌ 不适合作 alpha |
| volatility_60_cs | ~0.006 | ~0.08 | ~48% | ❌ 不适合作 alpha |
| pv_divergence_20_cs | ~0.020 | ~0.25 | ~52% | ⚠️ 边际 |

**关键结论：** 13 个因子中，仅 3 个 value 因子稳定通过 IC 门槛。技术类因子普遍未通过。这意味着组合的 alpha 来源非常单一，依赖 value 因子在各类市场状态下都能产生正超额 — 而这在 2017、2019、2020 等成长驱动的市场中被证伪。

### 4.2 Router 层（Regime 识别与 Sleeve 映射）

| 问题 | 严重程度 | 影响年份 |
|------|---------|---------|
| Range-bound 概率过高（>35% 主导超过 5/8 年） | 🔴 高 | 2017, 2019, 2021, 2023, 2024 |
| Trend-up 识别不足（强牛市未被捕捉） | 🔴 高 | 2017, 2019, 2020 |
| Overlay multiplier 经常接近 1.0（无强信号） | 🟡 中 | 2021（所有 multiplier ~1.0） |
| Defensive 在下跌中配置不足 | 🟡 中 | 2018, 2021 |
| Sleeve 映射滞后于市场状态变化 | 🟡 中 | 2021（风格切换） |

**核心问题：** regime router 倾向于判定市场为 range-bound（5/8 年主导），这导致过度依赖 reversal 和 volume_price sleeve，而这些 sleeve 在趋势市场中表现不佳。

### 4.3 组合构建层（Fast vs Phase2 差异）

基于 `fast_vs_phase2_attribution.py` 和已有分析：

- **交集率：** fast Top50 与 Phase2 实际持仓的交集率在部分周期偏低。
- **未买入原因分布：**
  - 涨跌停限制：约 5-10% 的高分股票无法买入
  - 停牌：少量但集中
  - 持仓延续（buffer）：约 15-25% 的持仓保持延续
  - 权重上限（2%）：限制了高分股票的集中度

详细的 fast vs Phase2 分解见 `docs/fast_vs_phase2_overlay_2025.md`。

### 4.4 成本层

| 年份 | D 平均周换手 | 平均周成本(bps) | 年化成本估算 |
|------|-------------|---------------|------------|
| 2017 | 38.7% | ~7.9 | ~3.9% |
| 2018 | 40.7% | ~8.3 | ~4.1% |
| 2019 | 38.7% | ~7.9 | ~3.9% |
| 2020 | 38.7% | ~7.9 | ~3.9% |

成本对收益有明显拖累（年化 3.9-4.1%），但在 D 的超额亏损（-4% 到 -20%）面前，成本不是主要问题。Alpha 不足是根本原因。

## 5. 核心问题的定量回答

### 5.1 失败年份是选股打分错了，还是打分正确但组合没有买到？

**答案：选股打分本身就错了，组合构建加剧了问题。**

- Alpha 层：多数技术因子 IC 未通过门槛，value 因子在成长驱动的市场中表现弱。
- 组合层：涨跌停过滤和持仓延续导致部分高分股票未能及时买入，但不是主要矛盾。

### 5.2 D 降低 reversal 后，是不是仍然过度暴露弱 sleeve？

**答案：是的。** Reversal 权重从 C 的 ~30% 降至 D 的 ~23%，但仍是多数年份的主导 sleeve。Reversal 仅在震荡市有效，在趋势市（2017、2019、2020）中持续拖累。

### 5.3 2019/2020 跑输强势指数，是因为缺少 beta/动量，还是价值和防御暴露拖累？

**答案：两者都有，但主要是缺少 beta/动量暴露。**
- D 的 momentum_120 权重仅 13-17%，远不足以捕捉趋势。
- 价值暴露在 2019 年成长行情中拖累。
- 防御暴露在反弹中起反作用。

### 5.4 2018/2021 熊市或切换期，defensive sleeve 是否真的提供保护？

**答案：部分保护，但远远不够。**
- 2018：defensive 权重 29%，但绝对亏损 -37.9%。在系统性熊市中，低波股票也会大幅下跌。
- 2021：defensive multiplier=0.84（低配），在下跌中反而缺失保护。

### 5.5 交易成本和换手是否把微弱 alpha 吃掉？

**答案：成本有影响但非主因。** 年化成本 ~4%，但 D 的平均年化超额亏损 ~6.4%。即使成本为零，仍有 ~2.4% 的超额亏损。Alpha 不足是根本矛盾。

## 6. 结论与下一步建议

### 6.1 失败主因排序

1. **Alpha 池质量不足（最大权重 ~50%）**：仅有 3 个 value 因子可靠，技术/动量/反转因子均未通过门槛。
2. **Regime router 过于保守（~25%）**：过度判定 range-bound，高配 reversal，低配 trend/momentum。
3. **组合构建约束（~15%）**：fast vs Phase2 的差距，持仓延续导致调仓迟缓。
4. **交易成本（~10%）**：年化 ~4%，对边际 alpha 有影响。

### 6.2 是否应继续 Regime Overlay 路线？

**继续但不扩大。** 当前 overlay 相对 baseline 有稳定改善（7/8 年），证明了 "不同周期使用不同策略" 的方向正确。但在底层 alpha 池质量提升之前，overlay 的上限很低。

### 6.3 下一步优先级

1. **Phase C：因子池重建。** 提升底层 alpha 质量，特别是引入质量因子（ROE、毛利率等）和改进动量因子。
2. **Phase D：Router 重构。** 降低 range-bound 的默认概率，增加 trend 灵敏度。
3. **Phase E：组合构建优化。** 缩小 fast vs Phase2 差距。
4. **Phase F：候选冻结与验证。**
