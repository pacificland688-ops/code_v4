# Sleeve 权重错配跨年验证

## 边界

- 固定使用同一套 regime overlay 配置，不搜索参数、不改策略。
- 每年单独闭合窗口诊断；2026 是 YTD，不与完整年份等同。
- 目标是验证 2025 发现的错配是否跨年份存在，而不是用这些结果直接调参。

## 初步判断

- `momentum_60_cs` 权重方向与 raw Top-Bottom 不一致的年份：0/1。
- 如果错配集中在少数年份，它更像市场阶段问题；如果多年反复出现，才考虑进入候选策略开发。
- value 仍需按 Phase1 原始面板 IC、weekly aligned IC、Top50 经济收益三层拆开看；不能只凭 Phase1 ICIR 决定加仓 value。

## 后续约束

- 暂不基于单年或单因子结果反转方向。
- 暂不搜索 IC 窗口、min_icir、weight cap。
- 若进入策略开发，候选规则必须先冻结，再做未参与设计年份的 OOS 复验。
