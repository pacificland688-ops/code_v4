## 初步判断

- `momentum_60_cs` 权重方向与 raw Top-Bottom 不一致的年份：1/9（2024）。
- `momentum_60_cs` 的 Top50 选股暴露方向不一致年份：2/9（2021、2024）。
- 结论：2025 观察到的 `momentum_60_cs` 错配不是多数年份稳定现象，更像特定市场阶段/组合构造下的问题；暂不支持直接反转或重写 momentum 因子方向。
- value 的 Phase1 与 weekly aligned ICIR 方向冲突年份：4/8（2018、2019、2024、2026）。
- value 的 Phase1 与 Top-Bottom 经济收益方向冲突年份：4/8（2018、2019、2024、2026）。
- 结论：value 在 2021-2023 的三层口径较一致，但 2018、2019、2024、2026 存在冲突；后续应先统一 Phase1、weekly aligned、Top50 经济收益口径，再决定是否提高 value sleeve 权重。
- 样本提醒：2026 是 YTD，不应和完整年份等权用于规则设计。

## 后续约束

- 暂不基于单年或单因子结果反转方向。
- 暂不搜索 IC 窗口、min_icir、weight cap。
- 若进入策略开发，候选规则必须先冻结，再做未参与设计年份的 OOS 复验。
