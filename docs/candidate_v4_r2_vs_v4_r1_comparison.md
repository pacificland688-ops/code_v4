## 3. 关键差异分析

### 3.1 因子构成变化

| 维度 | V4 R1 | V4 R2 |
|------|-------|-------|
| Alpha 因子 | 多个 momentum + growth + value | 仅 volatility_60_cs (defensive) |
| Gate 状态 | 部分 PASS | 全部 FAIL |
| 策略类型 | 多因子 alpha 候选 | 纯防御策略 |
| 候选池合规 | enabled 含 PASS 因子 | enabled 为空（NO_ALPHA_SOURCE） |

### 3.2 表现特征变化

1. **极端年份表现分化加剧**:
   - R2 在 2020 年（牛市）比 R1 差 33.4% — 因为 R2 没有 alpha 因子捕捉趋势
   - R2 在 2018 年（熊市）比 R1 好 13.6% — 防御特性在下跌市中提供保护

2. **换手率从 21.3% 降至 14.4%**: R2 的纯防御策略持仓更稳定，但这是牺牲 alpha 机会换来的。

3. **回撤从 -20.5% 改善至 -17.3%**: 验证了低波动策略的风险控制效果。

4. **2026 YTD 大幅逆转**: R2 +5.9% vs R1 -26.1%，纯防御在 2026 年震荡市中提供了显著保护。

### 3.3 策略适用场景

| 市场环境 | V4 R1 | V4 R2 |
|---------|-------|-------|
| 牛市/趋势上涨 | ✅ 优 | ❌ 跑输 |
| 熊市/趋势下跌 | ❌ 差 | ✅ 优 |
| 震荡市 | ❌ 差 | ✅ 优 |
| 高波动 | 中等 | ✅ 优 |

## 4. 结论

R2 相对 R1 的改进集中在：
- ✅ 回撤控制改善（-20.5% → -17.3%）
- ✅ 换手率降低（21.3% → 14.4%）
- ✅ 熊市/震荡市表现提升

R2 相对 R1 的恶化集中在：
- ❌ 平均超额大幅下降（-1.4% → -4.1%）
- ❌ 正超额年份减少（5/8 → 4/8）
- ❌ 牛市表现严重恶化

**整体判断**: V4 R2 本质上不是 V4 R1 的改进版本，而是退化为纯防御策略。这是因为 V4 R2 构建时所有 alpha 因子均未通过 gate，被迫仅使用 defensive sleeve。当 gate 产生 PASS 因子后，预期 V4 R2 的表现应显著优于 R1。
