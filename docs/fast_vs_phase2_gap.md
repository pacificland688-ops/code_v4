# Fast Top50 vs Phase2 持仓差异归因

生成日期：2026-06-11  
数据来源：`fast_vs_phase2_attribution.py` (2025 年分析)

## 1. 问题定义

Fast Top50 是简化回测（无交易约束，直接取 score 前 50），Phase2 是完整回测（含 tradable 过滤、持仓延续、成本、权重上限等）。两者之间若存在显著分歧，说明信号在穿透到真实组合时被交易约束吃掉。

## 2. 已知发现（基于 2025 年和 sleeve factor overlay 分析）

### 2.1 Fast vs Phase2 分歧程度

2025 年数据显示 fast 与 Phase2 存在显著分歧。具体表现为：
- 部分调仓周期中，fast Top50 的股票在 Phase2 持仓中的交集率偏低。
- Phase2 持仓倾向于延续上期持仓（buffer 效应），导致换仓滞后。

### 2.2 未买入高分股票的原因分布

| 原因 | 占比估计 | 说明 |
|------|---------|------|
| 涨跌停限制 | 5-10% | 涨停无法买入，跌停无法卖出 |
| 停牌 | <5% | 临时停牌股票被跳过 |
| 持仓延续 (buffer) | 15-25% | entry_rank/exit_rank 机制使调仓滞后 |
| 权重上限 (2%) | ~5% | 高分股票被 cap 限制 |
| 价格数据缺失 | <2% | 少量股票缺少有效价格 |
| 正常执行 | 55-65% | Fast 与 Phase2 一致的部分 |

### 2.3 持仓延续 (Buffer) 效应的利弊

**利：**
- 降低换手（~5-10% 换手降低）
- 减少交易成本
- 避免频繁买卖边缘排名的股票

**弊：**
- 在风格切换时反应迟钝（如 2021 年春节后）
- 新进入 Top50 的高分股票可能延迟 1-2 周才被买入
- 退出 Top50 的低分股票可能在组合中保留过久

## 3. 建议调整

### 3.1 短期调整（候选配置中实施）

1. **降低 buffer 门槛：** 将 entry_rank 从 top 60 放宽到 top 55，exit_rank 从 bottom 40 收紧到 bottom 45。
2. **提升换手上限：** 将 turnover_max 从当前值适度放宽（需逐案测试）。
3. **成本预算：** 设置每期成本预算上限而非严格换手限制。

### 3.2 中期优化

1. **分数强度权重：** 从等权切换为 score_strength 权重，给高分股票更高权重。
2. **行业中性约束：** 控制组合行业暴露与 CSI300 的偏离。
3. **市值中性约束：** 控制组合市值暴露与 CSI300 的偏离。

## 4. 与 Phase B 归因的关联

| Phase B 发现 | Fast vs Phase2 Gap 的角色 |
|-------------|--------------------------|
| Alpha 池质量不足（占失败 50%） | 主要矛盾 — 即使完美执行也无法解决 |
| Regime router 保守（占 25%） | 中等 — router 影响 sleeve 选择 |
| 组合构建约束（占 15%） | fast vs Phase2 gap 的核心来源 |
| 交易成本（占 10%） | 成本拖累 alpha |

## 5. 验收标准

- Fast Top50 年化超额（扣成本前）与 Phase2 年化超额（扣成本后）的差值应在 2-3% 以内。
- 若差值 >5%，说明组合构建层有显著问题需要修复。
- 逐期交集率应稳定在 60% 以上（剔除涨跌停/停牌影响后）。
